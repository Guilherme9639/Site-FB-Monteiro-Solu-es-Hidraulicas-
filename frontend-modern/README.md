# Frontend moderno — FB Monteiro

Esta é uma versão visual paralela do site institucional. Ela fica fora de
`frontend/`, que é a pasta atualmente publicada pelo Vercel, portanto não
altera o site em produção.

Para visualizar localmente sem publicar:

```powershell
python -m http.server 4174 --directory frontend-modern
```

Depois, abra <http://localhost:4174>.

As fotos usadas são as mesmas já aprovadas no projeto. O carrossel troca a
imagem automaticamente a cada 5 segundos e mantém navegação manual.
