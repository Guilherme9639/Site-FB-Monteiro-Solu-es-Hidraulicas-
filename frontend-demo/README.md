# Case demonstrativo — FINNOVA STUDIO

Esta é uma versão demonstrativa e anonimizada de uma landing page para o
segmento hidráulico. Ela não contém telefone, nome, logo ou dados reais de
cliente e pode ser publicada como case do portfólio da FINNOVA STUDIO.

Para visualizar localmente sem publicar:

```powershell
python -m http.server 4174 --directory frontend-demo
```

Depois, abra <http://localhost:4174>.

As imagens são ilustrações SVG demonstrativas. O carrossel troca a imagem
automaticamente a cada 5 segundos e mantém navegação manual.
